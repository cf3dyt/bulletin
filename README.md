# 📌 Bulletin

**Bulletin** is a minimalist, modern web application styled like an aesthetic cork bulletin board. Built using pure HTML, CSS, and JavaScript, it provides a warm, cozy space for friends, families, and teams to post updates, coordinate events, run polls, and collaborate using an integrated AI assistant.

---

## ✨ Features & Functionality

### 🪵 Aesthetic Design & Core UI
- **Cork-Board Theme:** Clean, modern interface designed with warm earth tones (shades of brown, cream, and off-white) reminiscent of a physical bulletin board.
- **Adaptive Layout:** 
  - **Desktop:** Collapsible left-hand navigation sidebar.
  - **Mobile/Tablet:** Intuitive bottom navigation bar.
- **Animated Floating Action Button (FAB):** Smooth expand/collapse animation for quick actions across all tabs.

### 👥 Groups & Onboarding
- **Interactive Onboarding:** Features a guided tutorial with "Sally & Friends" demonstrating how to create groups, share links, and navigate the app.
- **Create or Join Groups:**
  - Create custom bulletin groups with customizable settings.
  - Join existing groups via invite codes or direct sharing links.
- **Contacts & Invites:** Invite members directly using their Gmail address or phone number, or save contacts for quick group access.

### 📝 Multi-Tab Group Hubs
Each bulletin group contains dedicated functional tabs:
1. **Stream (Bulletin Post):**
   - Post updates with titles, descriptions, images, links, and audience targeting (share with everyone or select members).
   - Scrollable feed layout tailored for post viewing.
2. **Weekly Bulletin:**
   - Dedicated dashboard view summarizing recent activity and updates across all joined bulletins.
3. **Events & Calendar Sync:**
   - Create events with dates, times, locations, links, and essential notes.
   - Built-in permission request to sync events directly to device calendars.
4. **Polls:**
   - Run simple, interactive voting polls (similar to YouTube polls) for rapid decision-making.
5. **Gemini AI Helper:**
   - Integrated chatbot to ask questions about group schedules, events, or general bulletin updates.
6. **Settings:**
   - Account management, sync preferences, and permission controls.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6+)
- **Design System:** Custom CSS Grid & Flexbox layouts, CSS keyframe animations, Lucide SVG icon set
- **Data Persistence:** Browser `localStorage` (client-side storage)

## 🚀 Getting Started

1. **Clone or Download:** Download the project files.
2. **Run Locally:** Open `index.html` in any modern web browser—no complex setup or dependencies required!
3. **Deploy:** Upload to GitHub Pages, Netlify, or Vercel for instant free hosting.
